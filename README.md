## 🚀 Website Highlights & Features

- **Dynamic Interactive Canvas**: High-performance constellation particle network that moves smoothly with mouse and touch interactions.
- **Hero & Typewriter**: Multi-title animated typewriter showcasing core capabilities alongside a high-resolution portrait with floating badge animations.
- **The Modern Search Paradigm (SEO vs. AEO vs. GEO)**: Strategic interactive showcase illustrating how content is architected for traditional search (SEO), conversational answer engines (AEO), and generative AI models (GEO).
- **Interactive Skills Matrix**: Real-time filtering by *Content Strategy*, *Content Production*, *Product & Growth*, *AI & Technology*, and *Leadership*.
- **Professional Career Timeline**: Comprehensive chronicle of roles at **iFour Technolab Pvt. Ltd.**, **Variance Technologies Pvt. Ltd.**, and **EduTest Solutions**.
- **Product & Portfolio Showcase**: Featuring live properties including **PlusPhysio**, **PlusRadiology**, **PlusDoctor**, **PlusPedia**, **Office Add-ins**, and **iFour Author Articles**.
- **Dark & Light Mode Switcher**: Modern glassmorphic dark theme by default, with smooth toggle and `localStorage` persistence.
- **Print / Save CV as PDF**: Built-in `@media print` stylesheet that transforms the page into an executive 2-page resume with one click.
- **Zero-Dependency Architecture**: Built with modern vanilla HTML5, CSS3, and JavaScript—loads lightning-fast with 100/100 performance and zero build dependencies.

## 🛠️ Tech Stack

- **Markup & Semantics**: Semantic HTML5 with Schema.org JSON-LD structured data for Person and ProfilePage.
- **Styling**: Modern CSS3 (CSS Custom Properties, Glassmorphism, Flexbox, CSS Grid, Custom Keyframes).
- **Interactions**: Vanilla ES6+ JavaScript (HTML5 Canvas API, IntersectionObserver API, Clipboard API).
- **Typography & Icons**: Plus Jakarta Sans, Space Grotesk, JetBrains Mono, Font Awesome 6.5.
- **Deployment**: Automatic continuous deployment to GitHub Pages via GitHub Actions.

## 💻 Local Preview

To view the website locally:

1. Clone this repository:
   ```bash
   git clone https://github.com/panchalkapil/Kapil-Panchal-CV.git
   cd Kapil-Panchal-CV
   ```
2. Simply double-click `index.html` or open it with any local development server:
   ```bash
   # Using Python
   python -m http.server 8000
   
   # Or using Node
   npx serve .
   ```
3. Open your browser at `http://localhost:8000`.
